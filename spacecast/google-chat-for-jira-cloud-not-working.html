Google Chat for Jira Cloud not working

Setup problems with Google's "Google Chat for Jira Cloud" app come up regularly in the Atlassian Community, and the error codes it shows are not documented anywhere. This page collects the symptoms people report and the fixes that worked for some of them.

Where this comes from. We make Spacecast, a different app, and we do not run or support Google's app. The fixes below are ones other users and Atlassian staff have reported in public threads, linked in each section. We cannot promise they work for you.

1. An error code when you click Configure

Symptom. You add the Jira app to a space, click Configure, the browser opens Jira, and a short code such as 6PQ3DA, 171E8N, or KWAGX5 appears, often in the lower left corner.

What to try.

  • Install the Jira side of the app first. Atlassian Support's answer to the 6PQ3DA thread was that Jira shows this kind of error when the Chat app is configured before Google Chat for Jira Cloud is installed on the Jira site. A Jira admin installs it under Apps > Explore more apps, then you click Configure in Chat again.
  • Check you are signed in to the right Jira site in the browser that opens, with an account that can see the project.
  • Try a direct message with the app. One person in the same thread found the app worked one to one but not in spaces, which at least tells you the Jira side is installed correctly.

Several people in that thread said the error stayed after installing the app, and one noticed it mostly with team-managed projects. Nobody posted a fix for those cases, and the 171E8N thread has no answer either.

2. /jira_settings fails after you pick a project

Symptom. /jira_connect succeeds, /jira_settings shows the card, the project list loads, and choosing a project returns an error. Spaces you set up earlier keep working; new spaces, or edits to old subscriptions, fail.

What to try.

  • Uninstall and reinstall the app in Jira, then run /jira_connect and /jira_settings again. Some people report this clears it. The person who opened the 2025 thread had already tried it without success, and two others there had the same problem with no fix.
  • Use the support link shown with the error and include the hash and trace ID it gives you. In another thread, one person's setup started working after they wrote to support, though they never got a reply.

3. Project search or "All projects" does not load

Symptom. The configuration page opens, but the project picker stays empty or the "All projects" option does nothing.

What to try. Allow third-party cookies for the configuration page, or try a different browser. A reviewer on the app's Marketplace listing reported in February 2026 that allowing third-party cookies made project search work. The page loads inside a frame from another domain, which stricter browser privacy settings block.

4. Your Jira address does not end in atlassian.net

Google's app works with Jira Cloud only. If your Jira runs on your own domain as Jira Data Center or Server, the app cannot connect, and you will see an error code after Configure, as in this thread. You need an integration that supports Data Center, or a webhook from your own automation.

5. Nothing worked

If you only need notifications from Jira into Chat spaces, you have options that do not depend on Google's app:

  • No app at all. In the Chat space, add an incoming webhook under Apps & integrations > Webhooks. In Jira, create an Automation rule with a Send web request action that posts a JSON body such as {"text": "{{issue.key}} {{issue.summary}}"} to that URL. This is fine for a handful of simple alerts.
  • A Forge app. Several apps on the Atlassian Marketplace send Jira updates to Google Chat. Ours, Spacecast, is set up in Jira with one rule per space, has no per-user connect step, and is free for sites with up to 10 users. See how Google's setup maps to Spacecast rules.

If you rely on creating issues from Chat or on slash commands, Spacecast does not do that, so check what each app offers before switching.

6. Why this keeps happening

The Marketplace listing for Google Chat for Jira Cloud shows its latest version as 1.1.0-AC, released in November 2021. It is built on Atlassian Connect, the older app framework. Atlassian ends support for Connect on 31 January 2027 and says Connect features can be deprecated with little notice after that. Jira and browsers have both changed a great deal since 2021, so an app that has not been updated is more likely to hit problems like the ones above.
